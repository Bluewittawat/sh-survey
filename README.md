# แบบสอบถามผู้มีส่วนได้ส่วนเสีย SH1–SH4

แบบสอบถามออนไลน์ 4 ชุดสำหรับการปรับปรุงหลักสูตร ปวช. สาขาวิชาเตรียมวิศวกรรมศาสตร์ มทร.ล้านนา เชียงราย (พ.ศ. 2570)
เป็นหน้าเว็บ HTML ธรรมดา วางบน GitHub Pages ได้ฟรี และส่งคำตอบเข้า Google Sheets ผ่าน Google Apps Script
ไม่ต้องมีเซิร์ฟเวอร์หรือ hosting อื่น

| ชุด | กลุ่มผู้ตอบ |
| --- | --- |
| SH1 | สถานประกอบการ / นายจ้าง |
| SH2 | สถาบันอุดมศึกษา (ผู้รับผู้สำเร็จการศึกษาเข้าศึกษาต่อ) |
| SH3 | ศิษย์เก่า |
| SH4 | ผู้ปกครอง |

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
| --- | --- |
| `index.html` | หน้าเว็บทั้งหมด (HTML/CSS/JS ในไฟล์เดียว) และค่า `SCRIPT_URL` ที่บรรทัดบนสุด |
| `forms-spec.js` | ข้อคำถามทั้ง 4 ชุด (แก้ข้อคำถามที่ไฟล์นี้ไฟล์เดียว) |
| `Code.gs` | โค้ด Apps Script สำหรับวางใน Google Sheet ปลายทาง |
| `tests/` | สคริปต์ทดสอบด้วย Node |

---

## ขั้นที่ 1 สร้าง Google Sheet และวาง Code.gs

1. เปิด <https://sheets.new> เพื่อสร้าง Google Sheet ใหม่ ตั้งชื่อ เช่น
   `ผลการตอบแบบสอบถาม SH1–SH4 หลักสูตร ปวช. เตรียมวิศวกรรมศาสตร์ 2570`
2. เมนู **Extensions (ส่วนขยาย) > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` ออกทั้งหมด แล้ววางเนื้อหาจากไฟล์ `Code.gs` ในโปรเจกต์นี้ จากนั้นกด 💾 บันทึก
4. (แนะนำ) ไปที่ ⚙️ **Project Settings** แล้วตั้ง **Time zone** เป็น `(GMT+07:00) Bangkok`
5. กลับไปที่หน้าแก้โค้ด เลือกฟังก์ชัน `setupSheets` ในช่องรายการด้านบน แล้วกด **Run**
6. ครั้งแรก Google จะขอสิทธิ์ ให้กด **Review permissions** แล้วเลือกบัญชีของท่าน
   ถ้าพบหน้าจอ "Google hasn't verified this app" ให้กด **Advanced > Go to (ชื่อโปรเจกต์) (unsafe)** แล้วกด **Allow**
   (เป็นสคริปต์ของท่านเอง และเข้าถึงได้เฉพาะ Sheet นี้)
7. กลับไปที่ Google Sheet จะเห็นแท็บใหม่ดังนี้
   - `คำตอบ SH1` … `คำตอบ SH4`
   - `การโยงข้อคำถามกับ PLO` (ข้อคำถามร่วม / PLO / EC-ES และเกณฑ์แปลความหมายค่าเฉลี่ย)

## ขั้นที่ 2 Deploy เป็น Web app

1. ในหน้า Apps Script กด **Deploy > New deployment**
2. กดไอคอน ⚙️ ข้าง "Select type" แล้วเลือก **Web app**
3. ตั้งค่า
   - Description: `survey v1` (อะไรก็ได้)
   - **Execute as: Me**
   - **Who has access: Anyone**
4. กด **Deploy** แล้วคัดลอก **Web app URL** ที่ลงท้ายด้วย `/exec`
5. ทดสอบโดยเปิด URL นั้นในเบราว์เซอร์ ต้องเห็นข้อความ `Survey endpoint is running.`

## ขั้นที่ 3 ใส่ SCRIPT_URL และทดสอบ

1. เปิด `index.html` แล้วแก้บรรทัดบนสุด

   ```js
   const SCRIPT_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
   ```

2. ทดสอบในเครื่องก่อนได้ โดยเปิดไฟล์ `index.html` ด้วยเบราว์เซอร์
   (หรือรัน `python3 -m http.server 8000` แล้วเปิด <http://localhost:8000/?f=SH1>)
3. ทดลองตอบและส่ง **ทั้ง 4 ชุด** แล้วตรวจว่ามีแถวใหม่ในแท็บ `คำตอบ SH1` … `คำตอบ SH4`
4. ลบแถวทดสอบออกก่อนเปิดให้ตอบจริง (ลบเฉพาะแถวข้อมูล **ห้ามลบแถวหัวคอลัมน์**)

> ถ้ายังไม่ได้ตั้ง `SCRIPT_URL` หน้าเว็บจะแจ้งเตือนเมื่อกดส่ง และยังเก็บคำตอบไว้ในเครื่องผู้ตอบ

## ขั้นที่ 4 เผยแพร่บน GitHub Pages

1. สร้าง repository ใหม่บน GitHub แบบ **Public** (GitHub Pages ฟรีต้องเป็น public)
2. push ไฟล์ในโฟลเดอร์นี้ขึ้น branch `main`

   ```bash
   git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
   git push -u origin main
   ```

3. ใน repo ไปที่ **Settings > Pages**
   - Source: **Deploy from a branch**
   - Branch: **main** / **/ (root)** แล้วกด **Save**
4. รอ 1–2 นาที จะได้ URL เช่น `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

ลิงก์ที่ส่งให้ผู้ตอบแต่ละกลุ่ม:

```
https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/?f=SH1   สถานประกอบการ/นายจ้าง
https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/?f=SH2   สถาบันอุดมศึกษา
https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/?f=SH3   ศิษย์เก่า
https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/?f=SH4   ผู้ปกครอง
```

เปิด URL โดยไม่มี `?f=` จะเห็นหน้ารวมลิงก์ทั้ง 4 ชุด พร้อมปุ่ม "คัดลอกลิงก์"
(หน้านี้สำหรับผู้ดูแล ส่งลิงก์ `?f=SHx` ให้ผู้ตอบโดยตรง)

**ทางเลือก: Netlify Drop** — เปิด <https://app.netlify.com/drop> แล้วลากโฟลเดอร์นี้ (ต้องมี `index.html` และ `forms-spec.js`) ไปวาง
จะได้ URL ทันที แล้วต่อท้ายด้วย `?f=SH1` … `?f=SH4` เหมือนกัน

## ขั้นที่ 5 แก้ Code.gs ภายหลัง (ให้ URL เดิมใช้ต่อได้)

ถ้าแก้ `Code.gs` แล้ว **อย่า** กด New deployment เพราะจะได้ URL ใหม่ ให้ทำดังนี้

1. **Deploy > Manage deployments**
2. เลือก deployment เดิม แล้วกด ✏️ **Edit**
3. ช่อง Version เลือก **New version** แล้วกด **Deploy**

URL `/exec` เดิมจะใช้โค้ดใหม่ทันที ไม่ต้องแก้ `index.html`

## ขั้นที่ 6 ดูผลและสรุปผล

- คำตอบแต่ละชุดอยู่ในแท็บ `คำตอบ SH1` … `คำตอบ SH4`
  - คอลัมน์ A `เวลาที่ส่ง` และคอลัมน์ B `เวลาเริ่มทำ`
  - คอลัมน์ถัดไปเป็นคำตอบตามลำดับข้อ ข้อตาราง (grid) แยก 1 คอลัมน์ต่อแถว ในรูปแบบ `ข้อคำถาม [ข้อย่อย]`
  - ข้อระดับความคิดเห็นเก็บเป็นตัวเลข 1–5 คำนวณค่าเฉลี่ยได้ทันที
  - ข้อเลือกได้หลายข้อคั่นด้วย `, ` และคำตอบ "อื่น ๆ" ขึ้นต้นด้วย `อื่น ๆ: `
- **สรุปผล**: ใน Google Sheet จะมีเมนู **แบบสอบถาม > สรุปผล (summarize)**
  (หรือในหน้า Apps Script เลือกฟังก์ชัน `summarize` แล้วกด Run)
  ระบบจะสร้างหรืออัปเดตแท็บ `สรุปผล` ซึ่งแสดงผลทุกแถวของตารางและข้อ scale ในแต่ละชุด
  - จำนวนผู้ตอบ (n), ค่าเฉลี่ย (x̄), ส่วนเบี่ยงเบนมาตรฐาน (S.D. แบบกลุ่มตัวอย่าง n − 1)
  - การแปลความหมาย: 4.51–5.00 มากที่สุด, 3.51–4.50 มาก, 2.51–3.50 ปานกลาง, 1.51–2.50 น้อย, 1.00–1.50 น้อยที่สุด
  - ข้อคำถามร่วมจะแสดง PLO ที่โยงไว้
  - รันซ้ำได้ทุกเมื่อ (แท็บ `สรุปผล` ถูกเขียนใหม่ทั้งแท็บ อย่าพิมพ์อะไรเพิ่มในแท็บนี้)
  - คอลัมน์ที่นำมาสรุปคือคอลัมน์ที่ค่าทุกค่าเป็นจำนวนเต็ม 1–5

## ข้อควรระวัง

- **URL ของ Apps Script เป็นสาธารณะ** ใครที่มี URL ก็ส่งข้อมูลเข้ามาได้
  ระบบมีกันสแปมขั้นพื้นฐาน (honeypot, จำกัดจำนวนพารามิเตอร์และความยาว, กัน formula injection) แต่ไม่ได้ยืนยันตัวตนผู้ตอบ
  ควรตรวจข้อมูลก่อนวิเคราะห์
- **ห้ามเก็บข้อมูลอ่อนไหว** (เลขบัตรประชาชน ข้อมูลสุขภาพ ฯลฯ) ด้วยระบบนี้
- **ห้ามเปลี่ยนข้อความ `title` ของคำถาม** ใน `forms-spec.js` หลังเริ่มเก็บข้อมูล
  เพราะชื่อคอลัมน์มาจาก `title` ถ้าเปลี่ยนจะได้คอลัมน์ใหม่แยกจากของเดิม (รวมถึงข้อความแถวของตารางด้วย)
- ถ้าแก้ `CORE_ITEMS` ใน `forms-spec.js` ให้แก้ใน `Code.gs` ให้ตรงกันด้วย (Apps Script ไม่ได้อ่าน `forms-spec.js`)
- **แก้ข้อมูลผู้ติดต่อ** ใน `CONFIG.contact` ของ `forms-spec.js` (ตอนนี้ยังเป็น `โทร. [ระบุ] อีเมล [ระบุ]`)
- ระหว่างทำแบบสอบถาม คำตอบถูกเก็บชั่วคราวใน `localStorage` ของเบราว์เซอร์ผู้ตอบ และถูกลบเมื่อส่งสำเร็จ
  ถ้าใช้เครื่องสาธารณะร่วมกัน ผู้ตอบสามารถกด "ล้างคำตอบและเริ่มใหม่" ได้

```bash
node tests/run.js        # ตรวจข้อคำถาม, validation, payload และ Code.gs (ใช้ mock) ไม่ต้องติดตั้งอะไร

# ทดสอบในเบราว์เซอร์จริง + ถ่ายภาพหน้าจอ 360/1280 px ทั้ง light/dark (ไม่บังคับ)
npm i --no-save playwright && npx playwright install chromium
node tests/browser.js    # ภาพอยู่ที่ tests/screenshots/
```
